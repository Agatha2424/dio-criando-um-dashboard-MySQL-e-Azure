 ##Projeto:Criando um Dashboard corporativo com integração com MySQL e Azure

 Neste desafio, meu objetivo foi integrar uma base de dados MySQL hospedada na Azure com o Power BI e, a partir disso, realizar uma série de transformações para preparar os dados para análises mais estruturadas. Para iniciar o projeto, criei uma instância MySQL na Azure e explorei seus recursos básicos. Em seguida, utilizei o Cloud Shell para me conectar ao banco, ajustei as regras de firewall para liberar o acesso e concluí a conexão pelo MySQL Workbench. Com tudo configurado, avancei para a integração do Power BI com o banco hospedado na nuvem.

Depois da conexão, comecei o processo de transformação dos dados. Primeiro, revisei todos os cabeçalhos e tipos de dados, ajustando os campos monetários para o tipo double preciso. Também identifiquei valores nulos e avaliei quando seria adequado remover, manter ou preencher essas lacunas. Os registros de funcionários com Super_ssn nulo foram analisados, já que isso poderia indicar colaboradores em posição de gerência; além disso, verifiquei a existência de departamentos sem gerente e, quando necessário, completei esses dados assumindo que eu tinha acesso às informações corretas.

Outra etapa importante foi validar as horas registradas nos projetos e trabalhar com colunas complexas, separando ou transformando quando necessário. Em seguida, mesclei as tabelas employee e department para criar uma visão mais completa dos colaboradores com seus respectivos departamentos — sempre tomando cuidado para escolher o tipo de junção correto, já que isso interfere diretamente nos resultados. Nesse processo, eliminei colunas que não tinham utilidade para a análise.

Também realizei a junção dos colaboradores com os nomes de seus gerentes, podendo fazer isso tanto via SQL quanto com mescla no Power BI. Após isso, combinei os campos de nome e sobrenome para formar uma única coluna de identificação e mesclei os nomes dos departamentos com suas localizações, garantindo que cada combinação departamento–local fosse única, etapa essencial para modelos dimensionais futuros. Nesse caso, utilizei mesclar em vez de atribuir porque a intenção era combinar registros e não gerar novas linhas, mantendo a integridade da tabela original.

Por fim, agrupei os dados para descobrir quantos colaboradores cada gerente supervisiona e finalizei eliminando colunas desnecessárias, deixando o conjunto de dados limpo, organizado e pronto para ser usado em um modelo estrela e em análises no Power BI. Este projeto reforçou minha experiência com integração de dados em nuvem, SQL, Power BI e boas práticas de preparação de dados.
